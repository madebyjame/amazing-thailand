# THAI ESCAPE — Amazing Thailand

เว็บไซต์ประชาสัมพันธ์ท่องเที่ยวไทย **1 ภาค 1 จังหวัด ไม่ไปไม่รู้** พัฒนาจาก Figma และปรับประสบการณ์ใช้งานตามข้อเสนอแนะล่าสุด

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือเปิดโฟลเดอร์นี้ด้วย VS Code แล้วใช้ Live Server

เว็บนี้ใช้ **HTML, CSS, JavaScript และ Tailwind CSS** ไม่มี React, framework, backend หรือขั้นตอน build สำหรับเปิดใช้งาน

## เนื้อหาและการใช้งาน

- 6 ภาค: เชียงใหม่, บุรีรัมย์, พระนครศรีอยุธยา, จันทบุรี, กาญจนบุรี และกระบี่
- 27 สไลด์: Hero หน้าแรก + เลือกสไตล์วันหยุด + จังหวัดละ 4 สไลด์ + หน้าปิดท้าย
- แต่ละจังหวัดมีภาพรวม, แกลเลอรีสถานที่เที่ยว 4 แห่ง, อาหาร 3 เมนู และย่านพักพร้อมไอเดียทริป
- เมนูจุดหมายหุบไว้เริ่มต้น กดปุ่มมุมซ้ายเพื่อเปิด เลือกจังหวัด กดนอกเมนู หรือกด Escape เพื่อหุบ กดแท็บด้านบนเพื่อเปลี่ยนหัวข้อ
- จอคอมพิวเตอร์ขนาดเหมาะสม: หมุนล้อเมาส์หนึ่งจังหวะเพื่อเปลี่ยนสไลด์ ใช้ ↑ / ↓, Page Up / Page Down หรือปุ่มลูกศรมุมล่างได้
- มือถือและจอเตี้ย: เลื่อนอ่านตามปกติ เปิดเมนูจุดหมายจากมุมบนขวา
- ภาพเปิดจังหวัดเต็มจอและแกลเลอรีขนาดใหญ่ พร้อมแผง frosted glass และข้อความคอนทราสต์สูง
- ใช้โทนเย็นร่วมกันทั้งเว็บ: น้ำเงินเข้ม เขียวเข้ม และจุดเน้นฟ้า–มินต์ รวมถึงเมนู ปุ่ม และแผงอ่านเพิ่มเติม ลดความต่างของสีระหว่างจังหวัด
- แกลเลอรีเปลี่ยนภาพ ข้อความ และลิงก์ Google Maps ตามสถานที่ที่เลือก
- กดแผนเที่ยวเพื่อเปิดอ่านรายละเอียด
- ปุ่ม “อ่านเพิ่มเติม” ของทั้ง 24 หัวข้อเปิดแผงอ่านที่เลื่อนเข้าจากขอบซ้ายในหน้าเดิม พร้อมเรื่องน่ารู้ของสถานที่ทั้ง 24 แห่ง ไอเดียเที่ยว อาหาร และการเลือกย่านพัก
- แผงอ่านติดขอบซ้ายเต็มความสูง ไม่มีป๊อปอัปหรือฉากหลังมืด บนมือถือใช้พื้นที่เต็มหน้าจอ ปิดด้วยปุ่มกลับ Escape หรือคลิกพื้นที่ด้านนอก แล้วกลับไปยังตำแหน่งเที่ยวเดิม
- Hero เปิดด้วยภาพและข้อความเคลื่อนไหวเป็นจังหวะ หน้าที่เลื่อนถึงค่อยเผยเนื้อหา ปุ่มและการ์ดตอบสนองต่อการชี้และกด ส่วนแกลเลอรีเปลี่ยนภาพแบบ crossfade
- การข้ามจังหวัดใช้ View Transition เมื่อเบราว์เซอร์รองรับ และอุ่นภาพหน้าถัดไปเพื่อลดจังหวะรอโหลด โดยรองรับการลดแอนิเมชันตามการตั้งค่าระบบ
- ภาพที่เสิร์ฟใช้ WebP พร้อม `srcset` ขนาด 640, 960 และขนาดเต็ม เบราว์เซอร์เลือกตามหน้าจอและความละเอียด ไฟล์เต็มเบาลงประมาณ 31% จาก JPEG เดิม และเก็บต้นฉบับไว้สำหรับแก้ไขภายหลัง
- หน้าปิดท้ายหลังจังหวัดกระบี่มีลิงก์กลับไปสำรวจทั้ง 6 จังหวัด ปุ่มเลือกทริปอีกครั้ง กลับหน้าแรก และ Footer
- เปิดจากลิงก์หลักจะเริ่มที่ Hero โดยไม่จำตำแหน่งเลื่อนเดิม ส่วนลิงก์ตรงเข้าจังหวัดยังใช้ได้
- รองรับคีย์บอร์ด, reduced motion และลิงก์ตรงไปยังแต่ละสไลด์ เช่น `#krabi-places`

## โครงสร้างไฟล์

```text
amazing-thailand/
  index.html              โครงหน้าเว็บไซต์
  style.css               เลย์เอาต์แต่ละจังหวัดและ responsive
  experience.css          โทนสีเย็น กระจกเบลอ ภาพเต็มพื้นที่ และเมนูหุบ
  interaction.css         แอนิเมชันตอบสนองและหน้าตาแผงอ่านเพิ่มเติม
  app.js                  สร้างสไลด์และระบบโต้ตอบ
  data.js                 เนื้อหา ภาพ และข้อมูลจังหวัด
  guides.js               บทอ่านเพิ่มเติมของ 6 จังหวัดและ 24 สถานที่
  details.js              แผงอ่านจากซ้าย การปิด เปิด และโฟกัสคีย์บอร์ด
  motion.js               แอนิเมชัน Hero เผยเนื้อหา และเปิดแผนเที่ยว
  tailwind.config.js      ค่าตั้งต้น Tailwind
  tailwind.input.css      ต้นฉบับ utilities
  netlify.toml            ตั้งค่าการเผยแพร่แบบ static
  assets/
    tailwind.css          Tailwind ที่ compile พร้อมใช้งาน
    thai-mark.svg         ตราแบรนด์จากไฟล์ Figma
    images/               ภาพถ่าย 37 ภาพ พร้อม WebP หลายขนาดและ JPEG ต้นฉบับ
    fonts/                ฟอนต์ IBM Plex Sans Thai, Manrope และสัญญาอนุญาต
    photo-credits.json    รายละเอียดผู้ถ่ายและสัญญาอนุญาตภาพ
```

แก้เนื้อหาใน `data.js`, แก้หน้าตาพื้นฐานใน `style.css` และรายละเอียดดีไซน์ล่าสุดใน `experience.css`, แก้พฤติกรรมใน `app.js`

Tailwind ถูก compile เป็นไฟล์ในเครื่องไว้แล้ว จึงไม่เรียก Tailwind CDN หากเพิ่ม utility ใหม่ สามารถ compile อีกครั้งจากโฟลเดอร์นี้:

```sh
npx tailwindcss@3.4.17 -i tailwind.input.css -o assets/tailwind.css --minify
```

## GitHub Pages

1. สร้าง repository แล้วอัปโหลด **ไฟล์ภายในโฟลเดอร์นี้** ให้ `index.html` อยู่ที่ราก repository
2. ไปที่ Settings → Pages → Deploy from a branch
3. เลือก branch `main` และ `/ (root)` แล้วบันทึก
4. เปิดเว็บไซต์จาก URL ที่ GitHub แสดง

หากใช้ repository รวมหลายงาน ให้เก็บทั้งโฟลเดอร์แล้วใช้ URL ลงท้าย `/amazing-thailand/` โดยตั้งค่า Pages ให้ตรงกับตำแหน่งไฟล์

## Netlify

ลากโฟลเดอร์นี้ไปที่ Netlify Deploy หรือเชื่อม Git repository โดยไม่ต้องใส่ build command และตั้ง publish directory เป็น `.` หาก repository มีโฟลเดอร์นี้อยู่ภายใน ให้ตั้ง base directory เป็น `amazing-thailand`

## ดีไซน์และข้อมูลภาพ

[Figma Design](https://www.figma.com/design/V0hDkuY7EQeXbqT2l6XnnG?node-id=11-68)

ข้อมูลที่มาภาพจาก Wikimedia Commons และสัญญาอนุญาตเก็บใน `assets/photo-credits.json` ภาพอาหารเป็นภาพประกอบเมนู และภาพย่านพักอธิบายตามสถานที่จริง ไม่ได้ใช้แทนภาพของโรงแรมอื่น

ข้อมูลประชาสัมพันธ์อ้างอิงแหล่งข้อมูลการท่องเที่ยวที่เก็บไว้ใน `data.js` แผนเที่ยวเป็นไอเดียสำหรับปรับตามเวลาของผู้เดินทาง

ดีไซน์ล่าสุดขยายพื้นที่ภาพ หุบเมนูเริ่มต้น และใช้กระจกเบลอเฉพาะแผงข้อมูล ลดข้อความซ้ำ เพิ่มขนาดและคอนทราสต์ข้อความ โดยคงเนื้อหาการท่องเที่ยวทั้ง 6 ภาคไว้ครบ

ทดสอบใน Chrome ครบ 27 หน้า ที่ 1440×900, 1366×768, 1100×700, 1024×768, 768×1024, 390×844 และ 320×740 พร้อมตรวจเมนู แกลเลอรีทั้ง 24 ตัวเลือก แผนที่ ปุ่มเลื่อน คีย์บอร์ด โฟกัสหลังเปลี่ยนหน้า และการโหลดลิงก์ตรง มุมมองโทรศัพท์และแท็บเล็ตแนวตั้งใช้เมนูด้านบนและเนื้อหาแนวตั้ง ตรวจเพิ่มว่าหน้ากระบี่ไปต่อถึงหน้าปิดท้ายได้ และลิงก์เลือกจังหวัด เลือกทริป กลับหน้าแรก และการเลื่อนผ่าน Footer ใช้งานได้
